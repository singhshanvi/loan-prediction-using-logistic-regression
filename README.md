# Loan Prediction Using Logistic Regression

## Overview

This project predicts whether a loan application will be approved or rejected using Machine Learning.

## Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn

## Algorithm

* Logistic Regression

## Features Used

* Gender
* Married
* Dependents
* Education
* Self Employed
* Applicant Income
* Coapplicant Income
* Loan Amount
* Loan Amount Term
* Credit History
* Property Area

## Project Steps

1. Data Loading
2. Data Cleaning
3. Missing Value Handling
4. Exploratory Data Analysis
5. Data Encoding
6. Model Training
7. Loan Prediction
8. Accuracy Evaluation

## Result

The Logistic Regression model achieved approximately 79% accuracy in predicting loan approval status.

## Conclusion

Credit History was found to be one of the most important factors influencing loan approval.
